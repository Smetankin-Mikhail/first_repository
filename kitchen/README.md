# Кухня на неделю

Меню, рецепты с таймерами, список покупок и оценки блюд для двоих.

- `index.html` — сайт. Открывать по ссылке с ключом `#k=…`: так список покупок и оценки общие на обоих телефонах.
- `config.js` — настройки проекта Firebase (не секрет).
- `firestore.rules` — правила доступа к базе, вставляются в консоли Firebase → Firestore → Rules.
- `owner.json` — зашифрованные калории, деление порций и нормы. Расшифровываются только по ссылке владельца.

Ключи из ссылок в репозитории не хранятся.
